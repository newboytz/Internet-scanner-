### 🛠️ How to Install
Run these commands in your **Termux** or terminal:
### 1. Termux Setup

```bash

apt update && apt upgrade -y
```
### or
```bash
pkg update && pkg upgrade
```



```bash
git clone https://github.com/newboytz/Internet-scanner-.git
```
### 📂 Enter Directory
```bash
cd Internet-scanner-
```

```bash
python app.py
```
