### 🛠️ Tools Used
- **Termux** (Android Terminal)
- **Acode** (Code Editor)
- **Python Flask** (Backend)
### 🛠️ How to Install
Run these commands in your **Termux** or terminal:
### 1. Termux Setup

```bash

apt update && apt upgrade -y
```
### or
```bash
pkg update && pkg upgrade -y
```

## 🐍 Install Python
```bash
pkg install python
```
## 🛠️ Install Git
```bash
pkg install git
```
### 🌐 Install Flask
```bash
pip install flask
```
### 📂 Clone Repository
```bash
git clone https://github.com/newboytz/Internet-scanner-.git
```
### 📂 Enter Directory
```bash
cd Internet-scanner-
```
### 🚀 Run Project
```bash
python app.py
```
